# Exhibit

Exhibit is a research project exploring how to test software claims with reproducible experiments. The proposed workflow turns a claim into an observable check, executes it in a sandbox, and records the result and supporting artifacts.

## Status

The current tree documents the research stage. There is no application runtime or install command.

## Research directions

- Determine which claims can be tested against a clean checkout.
- Record the environment, command, and result needed to repeat each check.
- Distinguish a failed claim from an experiment that could not run.
